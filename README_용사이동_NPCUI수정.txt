# 용사 자연스러운 이동 + NPC UI 복구 수정본

## 수정 내용
- Player.exe 용사가 카메라 기준 위치에 맞게 그려지도록 수정했습니다.
- 클릭 이동 시 즉시 순간 이동하듯 딱딱하게 움직이지 않고 가속/감속 방식으로 이동합니다.
- 이동 중에는 걷는 프레임과 그림자/오라가 더 자연스럽게 보이도록 수정했습니다.
- NPC UI가 사라져 보이는 원인이었던 NPC 이미지 리소스 누락을 수정했습니다.
- NPC404 이미지 파일을 Assets 폴더에 다시 포함했습니다.
- XP 초원 배경 이미지도 Assets 폴더에 포함했습니다.

실행: DebugHeroFileDungeonRPG.sln 열기 → 빌드 → 실행
