# DebugHeroFileDungeonRPG - Secret Relation + Boss Gate

변경 사항:
- 이름 입력/`admin` 시작 화면 제거
- 새 게임 시작 시 바로 커스터마이징으로 진입
- 첫 던전 클리어 후 NPC 대화를 통해 플레이어가 `admin`으로 임시 기록됨
- NPC 관계 점수는 화면에 미리 공개되지 않음
- 선택지에 점수 표시 제거, 선택 후에만 관계 변화 로그 표시
- 기준치 도달 전까지 이름 변경 가능 여부를 알리지 않음
- 기준치 도달 시에만 이름 재등록 화면 등장
- 10단계 스토리 스테이지 순차 잠금 유지
- 보스가 있는 단계의 격리 기록이 다음 진행의 핵심 게이트가 되도록 메시지 개선
- 보스 HP/공격력 대폭 상향

실행: `DebugHeroFileDungeonRPG.sln` 열기
