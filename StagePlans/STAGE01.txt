휴지통 과부하
휴지통 아이콘이 변형된 적. Stage 1의 마무리 적 역할을 한다. 앞에서 정리한 파일 조각들이 모여 있는 느낌을 준다.
전투 흐름
플레이어는 Recovery Program 캐릭터를 움직여 파일 개체들에게 접근한다.
기본 공격과 스킬을 사용해 파일 개체를 정리한다.
전투는 일반 RPG에 가까운 액션 전투로 진행된다.
다만 전투 화면은 일반 RPG 필드가 아니라 Windows XP 바탕화면이다.
파일 개체들은 동시에 등장하지만, 플레이어가 처리하는 순서는 자유롭게 둘 수 있다.
난이도 조절이 필요하다면 새 폴더 무리와 진짜최종 파일이 먼저 적극적으로 움직이고, 깨진 바로가기와 휴지통 과부하는 조금 늦게 활성화되도록 구성할 수 있다.
비고
각 적의 구체적인 공격 패턴과 수치는 아직 확정하지 않는다.이 문서에서는 각 적의 역할과 이미지 방향만 정리한다.이 방식은 적을 하나씩 길게 등장시키는 구조보다 Stage 1의 호흡을 짧고 가볍게 만든다.플레이어는 바탕화면 전체가 갑자기 소란스러워지는 느낌을 받게 된다.

13. Stage 1 기획 메모
핵심 감각
핵심 문장Windows XP 바탕화면 위에서작은 복구 프로그램 캐릭터가파일과 폴더 괴물을 정리하는 액션 RPG 튜토리얼
NPC 표현 방식
Windows Recovery Assistant는 캐릭터가 포함된 Windows XP 스타일 알림창으로 대사를 전달한다.
NPC와 시스템 메시지는 분리되지 않는다.
알림창 자체가 Windows Recovery Assistant의 존재감을 담당한다.
플레이어 이름 처리
플레이어가 입력한 이름은 “복구 프로필 이름”으로 처리한다.
플레이어 캐릭터의 시스템상 이름은 Recovery Program으로 유지한다.
초반에는 이름 입력이 단순한 게임 진행용 프로필 설정처럼 보여야 한다.
후반부에서 이 이름을 다시 등장시키면, 플레이어가 입력한 이름이 단순한 닉네임이 아니었다는 식으로 회수할 수 있다.
전투 관련 메모
일반 전투 패턴과 스킬 구성은 아직 미정이다.
Stage 1 문서에서는 각 적의 역할과 이미지 방향만 정리한다.
구체적인 공격 방식, 쿨타임, 피해량, 스킬 키 배치는 추후 전투 시스템을 확정하면서 결정한다.
주의점
Stage 1에서는 후반 반전을 직접 암시하지 않는다.
“사용자”, “관리자 정체”, “너는 범인이다”, “User_Session.exe”, “shutdown”, “taskkill” 같은 요소는 사용하지 않는다.
초반에는 밝고 유쾌한 Windows XP 패러디 감성을 유지한다.
