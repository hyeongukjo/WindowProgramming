핵심 컨셉
Stage 2는 첫 번째 보스 스테이지이다.
Stage 1에서 생성된 Driver Vault.exe를 실행하면 Windows XP 장치 관리자처럼 보이는 공간으로 진입한다.
이 스테이지는 일반 몹전 없이 Driver-K 보스전 하나에 집중한다.
Driver-K는 오래된 장치와 드라이버를 계속 유지하려는 존재지만, 전투 중에는 플레이어의 복구 명령을 “장치 제거 시도”로 인식하고 적대적으로 반응한다.
초반에는 USB 인식 오류, 드라이버 충돌, 노란 느낌표 같은 Windows XP식 개그를 중심으로 보여준다.
보스전 중반부터는 Driver-K가 단순 악성 개체가 아니라 오래된 장치와의 연결을 지키려는 시스템 현상임을 약하게 드러낸다.
Stage 2에서 지켜야 할 점
일반 몹전은 넣지 않는다.
보스전 하나에 집중한다.
Windows XP 장치 관리자 UI를 적극 활용한다.
보스전이므로 Driver-K는 분명히 적대적이고 압박감 있게 등장한다.
노란 느낌표, 알 수 없는 장치, 드라이버 설치 마법사, USB 연결음 등을 사용한다.
Windows Recovery Assistant는 여전히 친절한 알림창 톤을 유지하되, 시스템 안정성을 우선하는 판단을 아주 약하게 보여준다.
후반 반전과 직접 연결되는 단서는 넣지 않는다.
Driver-K는 사악한 악당이 아니라, 낡은 장치를 지키려다 공격적으로 변한 경비형 보스처럼 보이게 한다.
2. 스테이지 진행 구조
진행 요약
Stage 2는 Driver Vault.exe 실행으로 시작된다.
플레이어는 장치 관리자 화면처럼 보이는 Driver Vault에 진입한다.
처음에는 단순한 장치 충돌 검사처럼 보이지만, 곧 Unknown Device 항목이 이상 반응을 일으키며 Driver-K가 등장한다.
Driver-K는 플레이어를 복구 프로그램이 아니라 장치 제거 명령을 가진 침입자로 인식한다.
이후 Driver-K와 보스전을 진행한다.
보스전 종료 후 Driver-K는 완전히 삭제되는 것이 아니라 드라이버 충돌이 해제된 상태로 복구된다.
클리어 후 다음 스테이지인 Windows Update 연구소로 연결된다.

4. Driver Vault 화면 구성
장면 목적
Stage 2의 전투 공간을 소개하는 장면이다. 장치 관리자 UI가 단순한 창이 아니라 보스전 필드로 확장될 수 있음을 보여준다.
화면 구성
화면 중앙에는 Windows XP 스타일의 큰 창이 열린다. 창 제목은 Driver Vault이다. 왼쪽에는 장치 목록 트리가 보인다.
Driver Vault+ Display Adapter+ Sound Driver+ USB Controller     ⚠+ Network Adapter+ Unknown Device     ⚠+ Legacy Device      ⚠
화면 연출
USB Controller, Unknown Device, Legacy Device 항목이 불안정하게 깜빡인다.
장치 목록의 줄들이 단순한 텍스트가 아니라 통로처럼 벌어진다.
장치 아이콘들은 바탕화면 위의 오브젝트처럼 입체적으로 떠오른다.
노란 느낌표 아이콘은 전투 경고 표시처럼 깜빡인다.
Driver Vault 창의 안쪽 공간이 확장되면서, 플레이어가 그 안으로 들어갈 수 있는 전투 필드가 된다.
비고
Stage 2의 배경은 판타지 던전처럼 보이면 안 된다. 반드시 Windows XP 장치 관리자 창이 변형된 공간처럼 보여야 한다.

12. Stage 2 기획 메모
핵심 감각
Windows XP 장치 관리자 창 안에서 오래된 드라이버 충돌이 보스화되고, 플레이어가 적대적인 Driver-K를 복구하는 첫 보스전
보스 의미
Driver-K는 단순한 악성 프로그램이 아니다.
오래된 장치와 드라이버를 계속 유지하려는 시스템 현상이다.
시스템에서는 충돌 원인으로 감지되지만, Driver-K는 자신을 오류로 인정하지 않는다.
그는 플레이어의 복구 명령을 장치 제거 시도로 받아들이고, Driver Vault 내부 접근을 막는다.
전투 중에는 공격적이고 고집스러운 보스처럼 보이지만, 후반부에는 그 공격성이 오래된 장치와의 연결을 지키기 위한 방어 반응이었음이 약하게 드러난다.
Driver-K 핵심 대사 방향
새로운 드라이버는 필요 없다.
나는 아직 작동 중이다.
연결을 끊지 마라.
충돌이 아니다. 호환되지 않는 것은 너희 쪽이다.
나는 오래된 것이 아니다. 나는 필요한 것이다.
NPC 표현 방식
Windows Recovery Assistant는 Stage 1과 동일하게 캐릭터가 포함된 Windows XP 스타일 알림창으로 대사를 전달한다. 아직은 친절하고 밝은 안내자처럼 행동한다. 단, 보스전 중간에는 시스템 안정성을 우선하는 기계적인 판단을 아주 짧게 보일 수 있다.
전투 관련 메모
Stage 2는 보스 스테이지이므로 일반 몹전은 넣지 않는다.
Driver-K 하나에 집중한다.
구체적인 공격 패턴, 피해량, 스킬 상성, 쿨타임은 아직 확정하지 않는다.
이 문서에서는 보스의 이미지, 등장 방식, 전투 흐름, 클리어 연출을 우선 정리한다.
주의점
Stage 2에서는 후반 반전을 직접 암시하지 않는다.
“사용자”, “관리자 정체”, “너는 범인이다”, “User_Session.exe”, “shutdown”, “taskkill” 같은 요소는 사용하지 않는다.
초반부이므로 Windows XP 특유의 오류 개그와 첫 보스전의 재미를 우선한다.
보스전이므로 Driver-K는 적대적이어야 하지만, 순수한 악당처럼 단순화하지 않는다.
