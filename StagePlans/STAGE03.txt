[Windows Update 연구소]

핵심 컨셉
Stage 3은 Windows Update 특유의 답답함과 반복되는 알림을 게임 플레이로 바꾸는 일반 스테이지이다.
플레이어는 업데이트가 멈추거나 실패하는 상황을 정리하면서 연구소 내부를 진행한다.
이 단계에서는 공포보다 “업데이트가 너무 오래 걸리고, 재시작 알림이 계속 뜨는 짜증”을 중심으로 분위기를 만든다.
다만 반복되는 알림과 진행률 정지는 약간의 불쾌함을 남겨, 후반부의 시스템 호러로 넘어갈 여지를 만든다.
Stage 3에서 지켜야 할 점
Windows Update 창, 진행률 표시줄, 재시작 알림, 업데이트 실패 메시지를 적극 활용한다.
일반 전투는 업데이트 UI 요소가 적으로 변형되는 방식으로 구성한다.
플레이어가 업데이트 연기 버튼을 누르는 장면은 넣을 수 있지만, 그 의미를 직접 설명하지 않는다.
Windows Recovery Assistant는 아직 친절하지만, Stage 1보다 약간 더 기계적인 안내문 톤을 섞는다.
“범인”, “내부 권한”, “정상적인 사용자라면” 같은 직접적인 반전 암시는 사용하지 않는다.
2. 스테이지 진행 구조
진행 요약
Stage 3은 Stage 2 클리어 후 생성된 Windows Update Lab.exe를 실행하면서 시작된다.
처음에는 평범한 Windows Update 창처럼 보이지만, 업데이트 진행률이 멈추고 창이 반복되면서 전투 구간으로 전환된다.
일반 전투는 업데이트 진행률이 올라가는 구간에 맞춰 단계적으로 진행된다.
주요 진행 순서
Windows Update Lab.exe 실행
Windows Update 연구소 진입
업데이트 준비 중 화면 확인
업데이트 UI 요소들이 적으로 변형
일반 전투 구간 진행
재시작 알림 이벤트
진행률 정지 및 업데이트 실패 구간
업데이트 재시도 후 클리어
System32 금지구역 연결
비고
구체적인 일반 전투 패턴과 스킬 상성은 아직 확정하지 않는다.
이 문서에서는 Stage 3의 화면 구성, 진행 흐름, 분위기, 주요 연출을 우선 정리한다.

4. Windows Update 연구소 화면 구성
장면 목적
Stage 3의 전투 공간을 소개하는 장면이다.
Windows Update 창이 단순한 메뉴가 아니라 연구소처럼 확장되는 공간임을 보여준다.
화면 구성
화면 중앙에는 Windows XP 스타일의 큰 업데이트 창이 열린다.
창 제목
Windows Update Lab
창 내부에는 업데이트 진행률 표시줄, 업데이트 목록, 재시작 알림 영역이 보인다.

업데이트 진행률 표시줄이 천천히 움직인다.
처음에는 정상적으로 보이지만, 진행률이 0%와 1% 사이를 반복하거나 갑자기 다시 0%로 돌아간다.
업데이트 창 뒤쪽에는 여러 개의 작은 업데이트 패키지 아이콘이 연구소 장비처럼 배치된다.
비고
Stage 3의 공간은 실험실처럼 보일 수 있지만, SF 연구소가 아니라 Windows Update 창이 확장된 공간처럼 보여야 한다.
진행률 표시줄, 업데이트 목록, 재시작 알림, 실패 메시지가 전투 공간의 핵심 오브젝트다.
5. Windows Recovery Assistant 안내
장면 목적

Windows Recovery Assistant는 여전히 친절하지만, 안내문은 업데이트 시스템처럼 조금 반복적이고 기계적으로 느껴져도 좋다.

6. 일반 전투 구간
장면 목적
업데이트 진행률이 올라가는 과정에서 업데이트 UI 요소들이 적으로 변형되는 일반 전투 구간이다.
Stage 1처럼 모든 적이 한 번에 소란스럽게 등장하는 방식이 아니라, 진행률 구간에 따라 적이 단계적으로 나타나는 방식으로 차별화한다.
전투 시작 화면
업데이트 진행률이 17%에서 멈춘다.
업데이트 목록의 KB 파일들이 흔들리고, 파란 업데이트 패키지 아이콘들이 화면 위로 튀어나온다.
진행률 표시줄이 길게 늘어지며 슬라임처럼 움직인다.
Windows Update 창 전체가 전투 상태로 바뀐다.
알림창 - Windows Recovery Assistant
업데이트 구성 요소가 활성화되었습니다.
멈춘 패키지부터 차례대로 정리해주세요.
[확인]
전투 대상
Update Patch 조각
파란 업데이트 패키지 아이콘이 변형된 기본 적. 여러 개가 몰려오는 느낌을 준다.
Loading Bar Slime
진행률 표시줄이 늘어졌다 줄어드는 적. 업데이트가 멈춘 듯한 답답함을 담당한다.
Restart Reminder
재시작 알림창 형태의 적. 팝업을 띄워 플레이어의 시야와 이동을 방해한다.
Failed Update
빨간 X가 붙은 업데이트 파일. 실패 후 재시도되는 느낌을 준다.
전투 흐름
업데이트 진행률 구간에 따라 적들이 단계적으로 등장한다.
업데이트 준비 중 0% ~ 17%: Update Patch 조각 등장
업데이트 설치 중 37%: Loading Bar Slime 등장
업데이트 구성 중 62%: Restart Reminder 팝업 난입
업데이트 실패 91%: Failed Update 등장
플레이어는 Recovery Program 캐릭터를 움직여 업데이트 개체들을 정리한다.
전투는 일반 RPG에 가까운 액션 전투로 진행되지만, 전투 화면은 Windows Update 창과 진행률 UI를 그대로 활용한다.
비고
구체적인 공격 패턴, 피해량, 스킬 상성, 쿨타임은 아직 확정하지 않는다.
이 문서에서는 각 적의 역할과 이미지 방향만 정리한다.
7. 재시작 알림 이벤트
장면 목적
Windows Update의 반복되는 재시작 알림을 게임 이벤트로 활용하는 장면이다.
이 장면은 후반부에서 회수할 수 있는 좋은 행동 기록이 되지만, Stage 3에서는 그 의미를 직접 설명하지 않는다.
화면 구성
전투 중 갑자기 Windows XP 스타일 재시작 알림창이 화면 중앙에 뜬다.
시스템 메시지
업데이트를 완료하려면 컴퓨터를 다시 시작해야 합니다.
[지금 다시 시작] [15분 후 알림] [나중에]
플레이어 조작
플레이어는 버튼 중 하나를 선택한다.
[지금 다시 시작]
현재 전투 중이므로 사용할 수 없음. 시스템이 “작업 진행 중” 메시지를 띄운다.
[잠시후 다시 알림]
Restart Reminder가 잠시 사라졌다가 일정 시간 뒤 다시 등장한다.
[나중에]
알림창은 닫히지만 이후 더 많은 Restart Reminder가 나타날 수 있다.
시스템 기록
플레이어가 [잠시후 다시 알림] 또는 [나중에]를 선택하면 짧은 시스템 기록만 남긴다.
시스템 기록
업데이트 알림이 연기되었습니다.
비고
이 기록을 Stage 3에서 의미심장하게 설명하지 않는다.
후반부에서 “최근 실행 기록”이나 “업데이트 연기 기록”으로 다시 등장시키면 자연스럽다.

9. 업데이트 실패 및 재시도

비고

실패 원인을 플레이어의 정체나 과거 행동과 직접 연결하지 않는다.

연결 설명
Stage 4는 보스 스테이지이다.
Stage 3에서 업데이트 문제를 해결한 뒤, 시스템 핵심 파일과 접근 제한을 다루는 System32 금지구역으로 이어진다.
Stage 4에서는 관리자 권한, 접근 제한, 보호된 시스템 파일을 중심으로 보스전을 구성한다.
12. Stage 3 기획 메모
핵심 감각
Windows Update 창 안에서
진행률 표시줄과 재시작 알림이 적처럼 변하고
플레이어가 멈춘 업데이트를 정리하는 일반 스테이지
NPC 표현 방식
Windows Recovery Assistant는 Stage 1, 2와 동일하게 캐릭터가 포함된 Windows XP 스타일 알림창으로 대사를 전달한다.
Stage 3에서는 여전히 친절하지만, 업데이트 안내문처럼 반복적이고 약간 기계적인 톤을 일부 섞을 수 있다.
플레이어 행동 기록
재시작 알림에서 [15분 후 알림] 또는 [나중에]를 누르는 행동은 후반부에서 회수할 수 있다.
하지만 Stage 3에서는 그 행동을 문제 삼지 않는다.
단순히 “업데이트 알림이 연기되었습니다.” 정도의 시스템 기록만 남긴다.
전투 관련 메모
Stage 3은 일반 스테이지이므로 일반 전투 구간을 포함한다.
전투 패턴, 피해량, 스킬 상성, 쿨타임은 아직 확정하지 않는다.
현재 문서에서는 업데이트 UI 요소가 적으로 변형되는 방식과 전투 흐름만 정리한다.
주의점
Stage 3에서는 후반 반전을 직접 암시하지 않는다.
“범인”, “내부 권한”, “정상적인 사용자라면”, “관리자 권한” 같은 표현은 사용하지 않는다.
업데이트 연기 행동은 플레이어가 자연스럽게 선택하게 만들되, 그 의미를 설명하지 않는다.
초반부이므로 Windows Update 특유의 답답함과 현실 공감 개그를 우선한다.
