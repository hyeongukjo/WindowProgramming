# 걷기 모션 자연스러움 보정 버전

수정 내용:
- Player.exe 캐릭터 디자인 유지
- 걷기 GIF 프레임을 실제 게임용 PlayerAgentWalk0~7.png로 추출하여 포함
- 프레임별 발 기준선과 중심을 맞춰 좌우 흔들림을 줄임
- 이동 거리 기준 WalkCycle 유지
- 보행 프레임 전환 속도를 약간 낮춰 끊김과 급격한 다리 움직임 완화
- 아주 작은 상하 무게중심 움직임만 적용해 사람처럼 조금 더 자연스럽게 보이도록 보정
- 기존 Stage 1 자동 보스전, 코인 상점, D/F 포션, NPC 중앙 에러창, XP 배경 기능 유지
