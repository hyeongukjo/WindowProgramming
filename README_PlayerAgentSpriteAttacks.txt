Player.exe AntiVirus Agent 스프라이트 적용 버전

변경 내용:
- 제공한 Player.exe AntiVirus Agent 이미지 스타일을 기반으로 한 스프라이트 시트를 Assets에 추가했습니다.
- 기존 Recovery Program 도형 캐릭터를 파란 보안요원형 Player.exe 캐릭터로 교체했습니다.
- Q/W 스킬은 SCAN/CLEAN 계열의 초록 치료 빔처럼 보이도록 수정했습니다.
- E/R 스킬은 DELETE 계열의 붉은 삭제 빔처럼 보이도록 수정했습니다.
- 이동 중 공격 보정, 코인 상점, Stage 1 Driver-K 자동 보스전, NPC 중앙 에러창 기능은 유지했습니다.

조작:
- 우클릭: 이동
- Space: 점프
- Q: SCAN
- W: CLEAN/치료
- E: DELETE
- R: 강한 DELETE
- D: HP 포션
- F: MP 포션
