스테이지별 픽셀 배경 적용 버전

적용 기준:
- 기존 DebugHeroFileDungeonRPG_WalkFinalSmooth 버전을 기반으로 함
- Stage 2부터 Stage 10까지 각 스토리 컨셉에 맞는 서로 다른 픽셀 배경 적용
- 보스방 배경도 가능한 스테이지마다 별도 이미지로 분리
- Stage 1 Driver-K 보스전은 Driver Vault 보스방 배경 사용

배경 매핑:
Stage 02 Driver Vault: 산업형 드라이버 격납고 / 보스방: 기계식 보스 아레나
Stage 03 Windows Update Lab: 업데이트 연구소 / 보스방: 엔진룸 대비 배경
Stage 04 System32: 금지된 시스템 신전 / 보스방: System32 심층 구역
Stage 05 Network Port: 네온 네트워크 항구 / 보스방: 포트 요새 전투 구역
Stage 06 Blue Screen Tower: 붕괴 중인 블루스크린 도시 / 보스방: 멜트다운 신전
Stage 07 Registry Hive: 레지스트리 기록 보관소 / 보스방: 의식형 아카이브 룸
Stage 08 Popup Error Maze: 오류창 미궁 / 보스방: 팝업 에러 아레나
Stage 09 Temp Cache: 깨진 데이터 동굴 / 보스방: 빛과 열의 캐시 코어
Stage 10 Recycle Bin: 산업형 휴지통 시설 / 보스방: 녹색 재활용 에너지 격리실

기존 기능 유지:
- Player.exe 캐릭터 보행/공격
- Stage 1 자동 Driver-K 보스전
- 보스 패턴
- 코인 상점 및 D/F 포션
- NPC 중앙 에러창
- 단일 공격 빔
