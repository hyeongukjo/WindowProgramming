# Stage 1 Auto Boss 적용 수정본

변경 사항:
- 기존 Stage 2에서 사용하던 일반 몬스터 정리 후 Driver-K 보스 던전 자동 전환 방식을 Stage 1로 이동했습니다.
- Stage 1: 파일 개체 몬스터 처치 → Driver-K 보스 던전 자동 진입 → Driver-K 보스 패턴 진행.
- Driver-K 보스 패턴(드라이브 조각 수집, DEBUG 아이콘 제거, ERR 구체 발사)을 Stage 1에서 사용합니다.
- Stage 2는 Driver-K 중복 보스를 제거하고 Driver Vault 잔여 드라이버 충돌 정리 스테이지로 변경했습니다.
- 코인 획득, 휴지통 상점, D/F 포션 사용 기능은 유지했습니다.
